# CRUD de Produtos com Java e PostgreSQL

Projeto desenvolvido para praticar operações CRUD (Create, Read, Update, Delete) utilizando Java e banco de dados PostgreSQL.

O sistema implementa o padrão DAO (Data Access Object) para manipulação dos dados e foi construído utilizando Maven no Eclipse.

## Funcionalidades

1. Listar produtos
2. Inserir produto
3. Atualizar produto
4. Excluir produto
5. Sair do sistema

## Estrutura do projeto

- Produto.java -> Classe que representa o produto
- ProdutoDAO.java -> Classe responsável pelas operações no banco de dados
- Principal.java -> Classe com menu para interação com o usuário

## Tecnologias utilizadas

- Java
- PostgreSQL
- JDBC
- Maven
- Eclipse IDE
